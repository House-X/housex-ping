# وكيل التداول الذكي — HOUSE X Trading Desk

وكيل ذكي يعمل كمحلل ومساعد تنفيذ **متوافق مع الشريعة الإسلامية**.
يحلل البيانات أولاً، يبحث في الأخبار، يقترح صفقات بخطة كاملة، ويفتحها ويديرها ويغلقها **بعد موافقتك فقط**.

## المبادئ الثلاثة (مفروضة في الكود — لا يستطيع الوكيل تجاوزها)

1. **الحلال فقط** — كل أصل يمر بفحص شرعي، ولا يُتداول إلا ما في قائمتك المعتمدة
2. **بلا رافعة إطلاقاً** — شراء فوري بالنقد المتوفر فقط، بلا هامش ولا اقتراض ولا بيع على المكشوف
3. **التحليل قبل التنفيذ** — يرفض النظام فتح أي صفقة دون تحليل حديث للبيانات خلال آخر 60 دقيقة

---

## ما الذي يفعله؟

| القدرة | التفاصيل |
|---|---|
| الفحص الشرعي | تصنيف كل أصل: متوافق / غير متوافق / يحتاج مراجعة — مع السبب والبديل الحلال |
| التحليل الفني | تحليل على عدة فريمات: الاتجاه، المتوسطات، القوة النسبية، الماكد، التذبذب، الدعوم والمقاومات |
| الأخبار والأساسيات | بحث مباشر على الإنترنت: البنوك المركزية، التضخم، الوظائف، تدفقات صناديق الكريبتو |
| خطة الصفقة | دخول، وقف خسارة، هدف، نسبة العائد للمخاطرة، حجم الصفقة، مستوى القناعة |
| إدارة المخاطر | قواعد مكتوبة في الكود لا يستطيع الوكيل تجاوزها |
| التنفيذ | شراء فوري، تعديل، وإغلاق — كل أمر يحتاج موافقتك |
| السجل والمراجعة | يُحفظ كل قرار مع سببه، ويراجع الوكيل أداءك ويكشف أخطاءك المتكررة |

---

## قواعد المخاطرة (قابلة للتعديل من ملف الإعدادات)

- الرافعة: **لا توجد** — ثابتة في الكود وغير قابلة للتعديل
- البيع على المكشوف: **ممنوع**
- أقصى خسارة لكل صفقة: **1%** من رأس المال
- أقصى نسبة من رأس المال في صفقة واحدة: **30%**
- إيقاف التداول اليومي بعد خسارة **3%**
- أقصى عدد صفقات مفتوحة: **3**
- أقل نسبة عائد إلى مخاطرة: **1.5**

## الضوابط الشرعية

| الأصل | الحكم في النظام | السبب | البديل الحلال |
|---|---|---|---|
| عملات رقمية فورية معتمدة | ✅ تداول | تملّك حقيقي | — |
| العقود الآجلة والدائمة | ❌ ممنوع | لا تملّك، رافعة، رسوم تمويل | الشراء الفوري |
| الفوركس | 📊 تحليل فقط | عقود فروقات بلا تقابض، رافعة، فوائد تبييت | تحليل الدولار كسياق للذهب والكريبتو |
| الذهب والفضة | 📊 تحليل فقط | عقود فروقات وآجلة بلا تقابض | ذهب فعلي أو منتج مخصّص معتمد شرعياً |
| المؤشرات | 📊 تحليل فقط | عقود فروقات | صناديق متوافقة مثل `SPUS` و `HLAL` |
| عملات الميم | ❌ ممنوع | غرر ومقامرة | — |
| أسهم وعملات أخرى | ⏸ تحتاج مراجعة | تحتاج فحص النشاط والنسب المالية | إضافتها للقائمة بعد المراجعة |

**قائمتك المعتمدة** في الملف
`sharia_universe.json`
— أنت (ومستشارك الشرعي) من يعدّلها، والوكيل يقرأها فقط.

> هذا فحص منهجي مبني على معايير شائعة مثل معايير هيئة المحاسبة والمراجعة للمؤسسات المالية الإسلامية، وليس فتوى. في المسائل الخلافية الكلمة الأخيرة لمستشارك الشرعي.

## التشغيل خطوة بخطوة

**1. التثبيت**

```bash
cd trading-agent
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

**2. الإعدادات** — انسخ ملف الإعدادات وضع مفتاحك:

```bash
cp .env.example .env
```

ثم افتح الملف وضع مفتاح
`ANTHROPIC_API_KEY`
من لوحة التحكم.

**3. التشغيل**

```bash
python main.py
```

**4. الفحص التلقائي لوقف الخسارة والأهداف** (كل 5 دقائق عبر الجدولة):

```bash
python main.py --check
```

**5. الاختبارات** (بدون إنترنت أو مفتاح):

```bash
pytest -q tests
```

## هيكل المشروع

```text
trading-agent/
├── main.py                 واجهة المحادثة في الطرفية
├── sharia_universe.json    قائمتك المعتمدة شرعياً
├── agent/
│   ├── config.py           الإعدادات وقواعد المخاطرة
│   ├── market_data.py      بيانات الأسعار (منصات الكريبتو + ياهو فاينانس)
│   ├── indicators.py       المؤشرات الفنية وملخص السوق
│   ├── risk.py             حجم الصفقة والتحقق من القواعد (بلا رافعة)
│   ├── sharia.py           الفحص الشرعي لكل أصل
│   ├── paper_broker.py     حساب المحاكاة وسجل الصفقات
│   ├── tools.py            الأدوات المتاحة للوكيل
│   ├── prompts.py          تعليمات الوكيل ومنهجيته
│   └── core.py             حلقة التفكير والتنفيذ
└── tests/                  اختبارات بدون إنترنت
```
