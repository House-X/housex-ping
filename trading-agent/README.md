# وكيل التداول الذكي — HOUSE X Trading Desk

وكيل ذكي يعمل كمحلل ومساعد تنفيذ للعملات الرقمية والفوركس والذهب والمؤشرات.
يحلل السوق، يبحث في الأخبار، يقترح صفقات بخطة كاملة، ويفتحها ويديرها ويغلقها **بعد موافقتك فقط**.

---

## ما الذي يفعله؟

| القدرة | التفاصيل |
|---|---|
| التحليل الفني | تحليل على عدة فريمات: الاتجاه، المتوسطات، القوة النسبية، الماكد، التذبذب، الدعوم والمقاومات |
| الأخبار والأساسيات | بحث مباشر على الإنترنت: البنوك المركزية، التضخم، الوظائف، تدفقات صناديق الكريبتو |
| خطة الصفقة | دخول، وقف خسارة، هدف، نسبة العائد للمخاطرة، حجم الصفقة، مستوى القناعة |
| إدارة المخاطر | قواعد مكتوبة في الكود لا يستطيع الوكيل تجاوزها |
| التنفيذ | فتح، تعديل، وإغلاق الصفقات — كل أمر يحتاج موافقتك |
| السجل والمراجعة | يُحفظ كل قرار مع سببه، ويراجع الوكيل أداءك ويكشف أخطاءك المتكررة |

---

## قواعد المخاطرة (قابلة للتعديل من ملف الإعدادات)

- أقصى خسارة لكل صفقة: **1%** من رأس المال
- إيقاف التداول اليومي بعد خسارة **3%**
- أقصى عدد صفقات مفتوحة: **3**
- أقل نسبة عائد إلى مخاطرة: **1.5**
- أقصى رافعة فعلية: **5x**

## التشغيل خطوة بخطوة

**1. التثبيت**

```bash
cd trading-agent
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

**2. الإعدادات** — انسخ ملف الإعدادات وضع مفتاحك:

```bash
cp .env.example .env
```

ثم افتح الملف وضع مفتاح
`ANTHROPIC_API_KEY`
من لوحة التحكم.

**3. التشغيل**

```bash
python main.py
```

**4. الفحص التلقائي لوقف الخسارة والأهداف** (كل 5 دقائق عبر الجدولة):

```bash
python main.py --check
```

**5. الاختبارات** (بدون إنترنت أو مفتاح):

```bash
pytest -q tests
```

## هيكل المشروع

```text
trading-agent/
├── main.py                 واجهة المحادثة في الطرفية
├── agent/
│   ├── config.py           الإعدادات وقواعد المخاطرة
│   ├── market_data.py      بيانات الأسعار (منصات الكريبتو + ياهو فاينانس)
│   ├── indicators.py       المؤشرات الفنية وملخص السوق
│   ├── risk.py             حجم الصفقة والتحقق من القواعد
│   ├── paper_broker.py     حساب المحاكاة وسجل الصفقات
│   ├── tools.py            الأدوات المتاحة للوكيل
│   ├── prompts.py          تعليمات الوكيل ومنهجيته
│   └── core.py             حلقة التفكير والتنفيذ
└── tests/                  اختبارات بدون إنترنت
```
