# وكيل التداول الذكي — مكتب التداول الشخصي

وكيل ذكي يعمل كمحلل ومساعد تنفيذ **متوافق مع الشريعة الإسلامية**.
يحلل البيانات أولاً، يبحث في الأخبار، يقترح صفقات بخطة كاملة، ويفتحها ويديرها ويغلقها **بعد موافقتك فقط**.

## المبادئ الثلاثة (مفروضة في الكود — لا يستطيع الوكيل تجاوزها)

1. **الحلال فقط** — كل أصل يمر بفحص شرعي، ولا يُتداول إلا ما في قائمتك المعتمدة
2. **بلا رافعة إطلاقاً** — شراء فوري بالنقد المتوفر فقط، بلا هامش ولا اقتراض ولا بيع على المكشوف
3. **التحليل قبل التنفيذ** — يرفض النظام فتح أي صفقة دون تحليل حديث للبيانات خلال آخر 60 دقيقة

---

## ما الذي يفعله؟

| القدرة | التفاصيل |
|---|---|
| الفحص الشرعي | تصنيف كل أصل: متوافق / غير متوافق / يحتاج مراجعة — مع السبب والبديل الحلال |
| الفحص الشرعي للأسهم | فحص تلقائي للأسهم الأمريكية والتركية: النشاط + نسب الديون والنقد والدخل المحرّم + نسبة التطهير |
| فرص البورصة التركية | مسح أسهم بورصة إسطنبول الأكثر سيولة، وترتيبها فنياً، وقياس أدائها بالدولار لا بالليرة فقط |
| فرص العملات الرقمية | مسح سوق بينانس الفوري: العملات الراسخة، والمدرجة حديثاً، والأكثر رواجاً |
| أبحاث العملات | ما تفعله العملة، اقتصاديات التوكن، مخاطر فك الحظر، نشاط المطورين، وفحص شرعي أولي |
| التحليل الفني | تحليل على عدة فريمات: الاتجاه، المتوسطات، القوة النسبية، الماكد، التذبذب، الدعوم والمقاومات |
| الأخبار والأساسيات | بحث مباشر على الإنترنت: البنوك المركزية، التضخم، الوظائف، تدفقات صناديق الكريبتو |
| خطة الصفقة | دخول، وقف خسارة، هدف، نسبة العائد للمخاطرة، حجم الصفقة، مستوى القناعة |
| إدارة المخاطر | قواعد مكتوبة في الكود لا يستطيع الوكيل تجاوزها |
| التنفيذ | شراء فوري، تعديل، وإغلاق — كل أمر يحتاج موافقتك |
| السجل والمراجعة | يُحفظ كل قرار مع سببه، ويراجع الوكيل أداءك ويكشف أخطاءك المتكررة |

## قواعد المخاطرة (قابلة للتعديل من ملف الإعدادات)

- الرافعة: **لا توجد** — ثابتة في الكود وغير قابلة للتعديل
- البيع على المكشوف: **ممنوع**
- أقصى خسارة لكل صفقة: **1%** من رأس المال
- أقصى نسبة من رأس المال في صفقة واحدة: **30%**
- إيقاف التداول اليومي بعد خسارة **3%**
- أقصى عدد صفقات مفتوحة: **3**
- أقل نسبة عائد إلى مخاطرة: **1.5**

## الضوابط الشرعية

| الأصل | الحكم في النظام | السبب | البديل الحلال |
|---|---|---|---|
| عملات رقمية فورية معتمدة | ✅ تداول | تملّك حقيقي | — |
| العقود الآجلة والدائمة | ❌ ممنوع | لا تملّك، رافعة، رسوم تمويل | الشراء الفوري |
| الفوركس | 📊 تحليل فقط | عقود فروقات بلا تقابض، رافعة، فوائد تبييت | تحليل الدولار كسياق للذهب والكريبتو |
| الذهب والفضة | 📊 تحليل فقط | عقود فروقات وآجلة بلا تقابض | ذهب فعلي أو منتج مخصّص معتمد شرعياً |
| المؤشرات | 📊 تحليل فقط | عقود فروقات | صناديق متوافقة مثل `SPUS` و `HLAL` |
| عملات الميم | ❌ ممنوع | غرر ومقامرة | — |
| أسهم وعملات أخرى | ⏸ تحتاج مراجعة | تحتاج فحص النشاط والنسب المالية | إضافتها للقائمة بعد المراجعة |

### الفحص التلقائي للأسهم — معيار هيئة المحاسبة والمراجعة رقم 21

| الشرط | الحد |
|---|---|
| النشاط الأساسي | ليس بنوكاً تقليدية أو تأميناً تقليدياً أو خموراً أو تبغاً أو قماراً |
| الديون الربوية ÷ القيمة السوقية | أقل من 30% |
| النقد والاستثمارات الربوية ÷ القيمة السوقية | أقل من 30% |
| الدخل المحرّم ÷ الإيرادات | أقل من 5% — ويُحسب لك مقدار التطهير |

الأنشطة المختلطة مثل الدفاع والفنادق والوساطة المالية تُعلَّم "تحتاج مراجعة" حتى لو نجحت النسب.
للأسهم التركية يقارن الوكيل النتيجة بمؤشرات المشاركة في بورصة إسطنبول.

### العملات الرقمية

الفحص الأولي يعتمد على تصنيف العملة: عملات الميم والقمار والإقراض بفائدة والمشتقات تُستبعد.
لكن **لا تُتداول أي عملة إلا بعد أن تضيفها بنفسك للقائمة المعتمدة**، لأنه لا يوجد معيار رقمي متفق عليه للعملات الرقمية كما في الأسهم.

**قائمتك المعتمدة** في الملف
`sharia_universe.json`
— أنت (ومستشارك الشرعي) من يعدّلها، والوكيل يقرأها فقط.

> هذا فحص منهجي مبني على معايير شائعة مثل معايير هيئة المحاسبة والمراجعة للمؤسسات المالية الإسلامية، وليس فتوى. في المسائل الخلافية الكلمة الأخيرة لمستشارك الشرعي.

## التشغيل خطوة بخطوة

**1. التثبيت**

```bash
cd trading-agent
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

**2. الإعدادات** — انسخ ملف الإعدادات وضع مفتاحك:

```bash
cp .env.example .env
```

ثم افتح الملف وضع مفتاح
`ANTHROPIC_API_KEY`
من لوحة التحكم.

**3. التشغيل**

```bash
python main.py
```

**التشغيل اليومي على ويندوز بنقرة واحدة:** انقر مرتين على ملف
`start.bat`
داخل مجلد المشروع. تُفتح نافذتان (الواجهة والمراقب) والمتصفح تلقائياً. اترك النافذتين مفتوحتين، وأغلقهما عند الانتهاء.

**3.5 الواجهة في المتصفح (موصى بها — تعرض العربية بشكل صحيح)**

```bash
streamlit run app.py
```

تفتح تلقائياً في المتصفح على العنوان
`http://localhost:8501`
وفيها: المحادثة، ومسح الفرص، والحساب، والقائمة الشرعية، وأزرار موافقة أو رفض لكل صفقة.

**4. مسح الفرص مباشرة** (بدون تكلفة ذكاء اصطناعي):

```bash
python main.py --scan bist       # البورصة التركية
python main.py --scan crypto     # العملات الراسخة على بينانس
python main.py --scan new        # المدرجة حديثاً
python main.py --scan trending   # الأكثر رواجاً
```

أو داخل المحادثة بالأمر
`/scan bist`

**5. الفحص التلقائي لوقف الخسارة والأهداف** (كل 5 دقائق عبر الجدولة):

```bash
python main.py --check
```

**6. الاختبارات** (بدون إنترنت أو مفتاح):

```bash
pytest -q tests
```

## الربط مع بينانس — التنفيذ الحقيقي

### ثلاث بيئات، بالترتيب

| البيئة | الإعداد | الأسعار | الأموال |
|---|---|---|---|
| المحاكاة الداخلية | `TRADING_MODE=paper` | حقيقية | وهمية داخل البرنامج |
| التداول التجريبي في بينانس | `TRADING_MODE=live` + `BINANCE_ENV=demo` | حقيقية | وهمية على حساب بينانس التجريبي |
| الحقيقي | `TRADING_MODE=live` + `BINANCE_ENV=live` | حقيقية | **حقيقية** |

### الحماية المبنية في الكود

- كل عملية شراء تُحمى فوراً على المنصة بأمر بيع مزدوج: وقف خسارة + جني أرباح. يعمل الأمر حتى لو أُغلق البرنامج أو الجهاز.
- مراقب احتياطي يغلق الصفقة إذا قفز السعر فوق مستوى الوقف أو تعذّر وضع أمر الحماية.
- سقف لقيمة الأمر الواحد: 50 دولاراً افتراضياً في المرحلة الأولى.
- في الوضع الحقيقي: يفحص النظام صلاحيات المفتاح، و**يرفض العمل** إن كان يسمح بالسحب أو التحويل أو العقود أو الهامش، أو إن لم يكن مقيداً بعنوانك.
- لا تُنفَّذ الأسهم عبر بينانس، فتبقى في المحاكاة.

### إنشاء المفتاح التجريبي

1. ادخل إلى صفحة التداول التجريبي في بينانس من حسابك
2. من إدارة المفاتيح أنشئ مفتاحاً جديداً
3. ضع المفتاح والرمز السري في ملف الإعدادات:

```bash
TRADING_MODE=live
BINANCE_ENV=demo
EXCHANGE_API_KEY=...
EXCHANGE_API_SECRET=...
```

4. افحص الاتصال:

```bash
python main.py --verify
```

### إنشاء المفتاح الحقيقي (بعد نجاح التجربة)

من إدارة المفاتيح في حسابك الحقيقي، فعّل **فقط**:

- ✅ القراءة
- ✅ التداول الفوري

واترك هذه **معطّلة**:

- ❌ السحب
- ❌ القروض والهامش
- ❌ العقود الآجلة والخيارات
- ❌ التحويل بين الحسابات

ثم قيّد المفتاح بعنوان الإنترنت الخاص بك.

### التشغيل اليومي

```bash
python main.py            # نافذة المحادثة مع الوكيل
python main.py --watch    # في نافذة ثانية: مزامنة الإغلاقات كل 30 ثانية
```

## تنبيهات تيليجرام، والمستكشف التلقائي، والاختبار التاريخي

### 📱 تنبيهات تيليجرام
تصلك رسالة عند فتح أي صفقة أو إغلاقها (وقف أو هدف)، وعند اكتشاف فرص جديدة.
1. في تيليجرام افتح
`@BotFather`
وأرسل
`/newbot`
ثم انسخ الرمز الذي يعطيك إياه
2. أضفه في ملف الإعدادات:
`TELEGRAM_BOT_TOKEN=...`
3. افتح البوت الجديد واضغط
`Start`
4. شغّل:
`python main.py --telegram-setup`
(يحفظ رقم المحادثة ويرسل رسالة اختبار)

### 💡 المستكشف التلقائي
أثناء عمل نافذة المراقب، يمسح الأسواق كل 4 ساعات (مجاناً)، ويختار المرشحين الأقوى المتوافقين شرعياً، ويدرسهم بالذكاء الاصطناعي حتى مرتين يومياً، ثم يرسل الخلاصة لتيليجرام ويعرضها في تبويب «فرص الوكيل». لا يفتح أي صفقة بنفسه.

### 🧪 الاختبار التاريخي
تبويب «اختبار تاريخي» في الواجهة، أو:
`python main.py --backtest BTC/USDT ETH/USDT --years 4`
